# .NET Interview Kit

A collection of AI skills and question banks for practising .NET developer interviews.

The kit helps you prepare for interviews covering C#, object-oriented programming, ASP.NET Core, Entity Framework Core, SQL, Azure, and system design.

## What's included

- **Interview skill** — Conducts interactive interviews, asks follow-up questions, and adapts to your answers.
- **Question banks** — Topic-wise questions organised by difficulty and experience level.
- **Evaluation rubric** — Provides consistent feedback on technical accuracy, depth of understanding, practical application, and trade-offs.

## How to use

Install the skill using a compatible AI coding assistant, then ask it to conduct an interview.

To install
```
gh skill install  https://github.com/DotNetInterviews/dotnet-interview-kit dotnet-interview
```

To update
```
gh skill update dotnet-interview
```

Examples:

- `Conduct a .NET interview for someone with 5 years of experience.`
- `Ask me OOP questions one at a time.`
- `Interview me on async/await in C# and ask follow-up questions.`
- `Give me a senior-level ASP.NET Core interview.`
- `Evaluate my answer and explain what I missed.`

The interview should proceed one question at a time, with feedback after each answer.
